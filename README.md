# Vitrina de Productos - Desafío Full Stack

Aplicación web funcional desarrollada con Spring Boot y Vanilla JS para explorar un catálogo de supermercado con más de 4.000 productos.

## Estructura del Repositorio
* `backend/`: Código fuente de la API REST (Spring Boot, Spring Data JPA, H2).
* `frontend/`: Interfaz de usuario estática integrada en el servidor backend.
* `docs/` o raíz: Documentación de arquitectura, especificaciones y gobernanza agéntica.

## Requisitos Previos
* Java 17 o superior.
* Maven 3.8+.
